# **App Name**: Lunara: AI Fertility Companion

## Core Features:

- User Authentication & Onboarding: User authentication and onboarding with Google sign-in, menstrual cycle input, and Google Fit integration.
- Fertility Dashboard: A dashboard providing a daily fertility score, calendar view, and mood log.
- AI Chatbot Assistant: AI-driven chatbot assistant named 'Luna' answering fertility questions, suggesting tips, and providing reminders.
- BBT and Ovulation Estimation: AI model or cloud function estimating BBT and time to ovulation.
- Settings and Privacy: A settings page allowing users to manage Google Fit permissions, export reports, set privacy preferences and activate 'Incognito Mode'.
- Personalized fertility insights: Generative AI tool creates daily, personalized insights.
- Reporting: Generates exportable report of historic logs.

## Style Guidelines:

- Primary color: Lavender (#E6E6FA) for a calming and sophisticated feel.
- Background color: Seashell (#FFF5EE) to provide a soft, warm whitespace.
- Accent color: Peachpuff (#FFDAB9) for highlights and CTAs.
- Body and headline font: 'Lora' (serif) for an elegant, readable style. Note: currently only Google Fonts are supported.
- Mobile-first, responsive design using cards for daily logs and progress rings for scores.
- Subtle animations for transitions and data updates to enhance user experience.
- Minimalist icons, using a line style with rounded ends where possible.
